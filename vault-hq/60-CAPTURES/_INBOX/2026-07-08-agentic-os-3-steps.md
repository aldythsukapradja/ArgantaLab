## 1. Raw Signal
A creator's 3-step recipe for a personal "Agentic OS": **(1) map your brain** — Obsidian + a graph
plugin (Graphify), "every note links into a graph Claude can traverse, no database"; **(2) build it** —
point an agent (his "PAUL") at the brain to generate a dashboard OS (commands: /connect, /index-brain,
/build-os, /ship-it, /watch); **(3) ship it** — keep local or push to GitHub + host on Railway to run 24/7.
Built on Claude Code, "any model — Opus/Fable not required."

## 3. Extracted Principle
The architecture I'm building is a recognized pattern, not a one-off: **markdown-graph brain (no DB) →
agent reads it → generates a dashboard OS → hosted to run continuously.** Independent validation that the
"single source of truth = linked markdown Claude traverses" bet is sound.
