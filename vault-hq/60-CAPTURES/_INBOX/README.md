# 📥 _INBOX — raw drops

Zero-friction intake. Every raw input lands here as **one new file**:
`YYYY-MM-DD-HHMM-<slug>.md`, `status: raw`, `promoted: false`.

- Claude Code writes only here. It never touches distilled notes.
- Never append to a shared file — one capture, one file (keeps git conflict-free).
- Nothing here is trusted or organized. Organizing happens at **harvest** (see [[DIGEST]] §5),
  not at capture.

Harvest in the evening [[daily-loop]]: read each note, distill the keepers into the right
folder, archive the rest, flip `promoted: true`.
