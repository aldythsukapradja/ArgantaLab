# 🗄️ _ARCHIVE — interesting, not useful now

The landing zone for the `archive` intent class: captures worth keeping but not worth
acting on or distilling right now.

- Moved here from `_INBOX/` at harvest, or classified straight here.
- Keeps the inbox clean without deleting anything.
- Revisit occasionally — an archived capture can become relevant later and get promoted.

See [[DIGEST]] §3 (intent classes) and §5 (harvest).
