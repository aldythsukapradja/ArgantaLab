# Prompt — Quest Design System

> [!success] 🟢 CANONICAL v1 · ArgantaLabs · updated 2026-06-15

For generating [[argantalab|ArgantaLabs]] quest chains that respect the engine's design laws.

## Prompt body
> Design a 5-step quest chain for a 9-year-old practicing multiplication. Constraints: 12-minute daily session, daily XP cap (see [[argons-economy|Argons Economy]]), difficulty rises only after two clean days, and every step maps to a curriculum node a parent can read in one sentence. Deliver: chain table, XP schedule, failure-day behavior.

## Grading
- Marathon rule: a kid who plays every day for a week must NOT finish the season early
- Parent-legibility: each node explainable at dinner
