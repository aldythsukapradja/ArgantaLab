# Product Loop

> [!success] 🟢 CANONICAL v1 · HQ · updated 2026-07-02

One family, four surfaces, a single flywheel:

1. **Organize** — the parent runs the week in [[kinetikcircle|KinetikCircle]]
2. **Learn** — the kid clears a quest in [[argantalab|ArgantaLabs]]
3. **Bloom** — effort waters the family plot in [[lashirabloom|LashiraBloom]]
4. **Observe** — the founder reads the pulse in [[circle-hq|HQ]] and tunes the loop

Each hop mints or spends **Argons** (see [[argons-economy|Argons Economy]]), so the loop is measurable end-to-end.

> The loop is the product. The apps are just doors into it.

## Loop health metrics
| Hop | Metric | Target |
| --- | --- | --- |
| Organize → Learn | quest-open rate from planner | 40% |
| Learn → Bloom | XP→bloom conversion | 90% |
| Bloom → Organize | next-morning planner return | 70% |
