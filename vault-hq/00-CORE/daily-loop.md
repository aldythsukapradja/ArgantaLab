# Daily Loop

> [!success] 🟢 CANONICAL v1 · updated 2026-07-07

> The habit loop that makes the system serve me. Not a checklist — a rhythm. The loop IS the
> twin's training data: every harvest feeds [[persona-core]], every route confirms [[effort-scorer]].

## ☀️ Morning — Orient (5 min)
- Open [[roadmap-tracker]] and [[coverage-tracker]].
- Read ONE number: `coverage.pct`.
- Read the top item in the Circle HQ verdict queue.
- Don't plan from scratch — ask the system "what's the highest-leverage open thing" and let
  the ladder-to-a-lever discipline answer. This replaces reacting to whatever's loudest.

## 🧭 Midday — Route (ongoing)
- Every task: run [[effort-scorer]] mentally before touching a model.
- One question: frame-inventing or frame-filling?
- Frame-inventing → Opus/Fable. Frame-filling → Sonnet/Haiku.
- Stops me burning premium capability on execution.

## 🌙 Evening — Harvest (10 min)
- Apply [[skills-index#context-compaction]] to myself.
- What got decided today? What's still open?
- Distillation goes to [[projects-moc|10-PROJECTS]] — never raw, never straight to a shipped/wiki state.
- This is what keeps [[persona-core]] fed with real judgment instead of going stale.

## 📅 Weekly — Verify (30 min)
- The honesty check. What's marked "done" that was never adversarially verified?
- Re-pull `coverage.pct` — did the week's work actually move it, or did it just feel productive?
- This is the loop's immune system against vanity progress.
