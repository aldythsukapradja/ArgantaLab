## Provenance log (the practice that makes filing possible later)

Every brand asset gets a record at creation — this is already half-built: the Brand OS's agent lane is git (authorship, dates, hashes for free), and generation briefs require tool disclosure.

Minimum fields: asset id · brand · creator (human/AI/hybrid) · tool + prompt ref · human edits · date · source file (repo path) · first public use (URL + screenshot) · license of any third-party input · founder approval ref.

**AI-assist rule:** AI-assisted ≠ AI-authored. Record the human contribution explicitly (selection, direction, editing) — this materially affects copyright posture in most jurisdictions. ChatGPT's returned packs must carry their provenance note (required in [[ChatGPT Visual Production Handoff]] §5).

## Standing rules

1. Git is the specimen vault: marks-as-data + rendered exports = dated, hashed evidence with zero extra effort.
2. Screenshot the @argantalab profile + top posts quarterly → `refs/evidence/` (founder, 10 min).
3. No public use of an unsearched name (Spark/Seed rule).
4. Third-party assets (Kenney tiles, fonts, NexusTK-derived sprites) each need a license line in the log **before** any commercial launch — flag: NexusTK-derived material is `requires-validation` for commercial use.
5. Kids' content: a parent-consent record precedes any real child creation appearing in marketing (template in F7's consent string).
