# Battle Command Center — v2 concept (Overview + Combat)

`docs/lashirabloom/battle-command-center-v2.md` · verdict **current**

Its information architecture — separate Overview / Combat (dials only) / Bestiary (scalable monster DB) / Rewards tabs + a persistent Publish bar — is the tab structure that actually shipped.

**Lesson:** The reframe that stuck: organize a command center by the entities you command (balance-dials vs author-database vs ship-publish are opposite UI needs), which fixed both the 'ugly/empty' and the 'doesn't scale' problems at once. Rewards/boss/PvP-reward schema it specced remained partly unbuilt.
