# LashiraBloom — Economy, Combat & Retention Remap

`docs/lashirabloom/economy-combat-remap.md` · verdict **partial**

The gather→craft→fight loop with gear ATK/DEF tiers and rescaled tiered monsters was partly built (gear + bestiary are in the tuning pipeline) but material-refining sinks (smelt/cook/sockets) and full retention scaffolding remain unbuilt.

**Lesson:** Diagnosed the core flaw honestly — dead-end materials (ore/gem/fish had no sink) and trivial 100-HP mobs vs 600+ damage — and closed the loop by making each gathered material a gear input.
