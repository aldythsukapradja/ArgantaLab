# Kingdom of Kin — AI Pixel-Art Pipeline

`docs/kingdom-of-kin/pixel-art-pipeline.md` · verdict **concept-unbuilt**

Describes a PixelLab data-driven sprite factory feeding a PixiJS KinSprite/installAtlas seam for Kin sprites; that Kin-art build never happened (Kingdom uses extracted NexusTK client art). PixelLab is adopted repo-wide (KB §7) but not for this Kin factory.

**Lesson:** The 'style-lock first / AI for the long tail, humans for hero pieces' pipeline thinking is sound and reused at the org level, but the specific Kin-sprite factory died with the Kingdom-of-Kin concept.
