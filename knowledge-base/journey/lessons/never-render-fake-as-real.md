# Provenance-badge every value so a dashboard over an empty room never lies

> [!quote] The principle
> Nothing fake renders as real. Every number carries a badge — live / partial / simulated / placeholder — and a simulated number is never printed bare. Honesty about emptiness is a feature, not an apology.

## Evidence
- KB decision log: "Bridge = deterministic seed, provenance-badged — nothing fake renders as real" (still holds). `apps/mcp/README.md` — the Bridge is honest *because* every value is badged; that same honesty exposes it as "a truthful dashboard over an empty room" (debt D8).
- `supabase/SPINE_CONTRACT.md` — `w2f_weekly` ships badged `partial` with an explicit ⚠ to validate against real data before flipping to `live`, "so a dashboard over an empty room never lies."
- `apps/hq/COMMAND_AUDIT_TRAIL.md` — the Low case is kept structurally unprofitable and simulated revenue is badged, "never printed bare." The standing admitted gap: provenance still mostly simulated (D8).
- `CONCEPT_JARVIS_CEO.md` — the doc's own honesty caveat ("headless preview is 0×0, the 3D reactor needs the founder's eyes") flags a build-review-adjust loop rather than a false "done."
- `docs/fable handoff/vault/00-CORE/persona-core.md` — every claim tagged `#known` vs `#inferred`, with 5 open questions the twin must not treat as settled. `RECON.md` self-flags that the repo was never scanned. The discipline is the product.

## The pattern
When a system's data is mostly simulated (as HQ's is, gated behind zero external users), the ethical and practical move is to make the simulation *visibly* simulated. A badge turns "an honestly-labelled lie" (D8's own phrasing) into a truthful instrument you can still reason over — and it makes the day the numbers go live unmistakable.

## Watch for
- The badge that never flips. `w2f_weekly` `partial`, HQ `simulated`, the 15 `placeholder` graph nodes — provenance badges are only honest if someone eventually earns the flip to `live`. Fixing D1 (real users) is what flips them.
- "Ownership" or "done" asserted in a map before the code is true (`knowledge-graph-map.md` claimed 15 blind nodes "now owned"; they stayed blind). A doc asserting closure the code never delivered is the opposite of a provenance badge.
- Presenting a `simulated`/`placeholder` value as measured in any brief, deck, or CEO answer — the one thing the Bridge contract forbids.
