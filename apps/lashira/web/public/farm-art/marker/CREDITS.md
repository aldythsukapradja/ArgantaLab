# Map-marker + animal-HUD icons — attribution

These flat SVG icons (castle, shield, cooking, festival, sword, seed, cart,
anvil, livestock, ribbon, coin, trophy, fish, feed, heart_low/mid/high) are
**hand-authored originals** for this project, not sourced from an external
icon pack — no license or credit required.

They replace raw emoji drawn via canvas `fillText`, which silently fails to
render on some mobile browsers/webviews (canvas text has no automatic
emoji-font fallback the way HTML text does). Same visual role as the emoji
they replace, single flat fill (`#f3f7fb`, matching the produce badge style)
so they read clearly against the colored marker discs.
