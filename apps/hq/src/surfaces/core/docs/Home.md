# Arganta Core — Field Guide

Arganta Core is your **digital-twin operator**: a chat that makes real things on your own infrastructure — images, voice, websites, single-file apps, decks, brand kits and data charts — and can delegate to your C-suite offices. It never fakes an answer: every message carries truthful provenance, and if a model isn't reachable it says so instead of pretending.

## The one rule

Core makes things **with tools, not with words**. Ask it to *make*, *build*, *generate*, or *show* something and it calls a real tool. Ask it a question and it answers in text. Either way the footer under each reply tells you the exact model, provider and cost — no generic labels.
