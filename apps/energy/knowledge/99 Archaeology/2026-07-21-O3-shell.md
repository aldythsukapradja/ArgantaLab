# 2026-07-21 — Batch O3: shell + Foundation / Data / Knowledge tabs (append-only)

Built the ArgantaEnergy operator workstation from scratch in `apps/energy` (Vite +
React 18 + TypeScript 5, strict, port 5279). Earlier deleted build replaced; only
`{scripts,knowledge,.env,.gitignore}` pre-existed. `tsc --noEmit` clean, `vite build`
green, dev server verified in-browser (desktop 1440×900 + mobile 375×812).

## Architecture
- **Shell** (handoff §8): 58px activity rail · 54px context bar (brand, field/well
  selector, ⌘K, route badge) · 38px domain tab bar · workspace · 26px mono audit
  status bar. **Config-driven nav** — `src/nav.ts` `DOMAINS[]` is the single source;
  rail + tab bar + command palette all render from it (the reusable Cosmo pattern).
- Locked **sibling-apps switcher** slot (Circle HQ / Market Radar, locked). Floating
  **agent-orb** slot reserved (P4, reduced-motion-safe pulse, not wired).
- Design tokens verbatim from handoff §8 (`src/theme.css`): `--bg #071014` … teal/
  amber/blue/violet/rose/orange semantics, mono for IDs/units/timestamps, square
  low-radius panels, hairline borders, technical dot/grid backdrops, minimal motion.
  `:focus-visible`, `prefers-reduced-motion`, WCAG-AA contrast.

## Data seam (real values only)
- `scripts/build-data.mjs` (predev/prebuild, zero-dep Node) reads canonical
  `data-energy/{processed,manifest}` and emits lean `src/data/*.json` (git-ignored).
  NO fabrication: numbers are either **computed** at build time (well/wellbore/traj/
  horizon counts, production rows, mirror bytes/sha256, top-folder rollup) or pulled
  from the **O2 QC product** and tagged `qc` (the 65.7M log-value total, not cheaply
  recomputable client-side). Every metric carries a source-path note.
- **Provenance discrepancy surfaced honestly:** `mirror-report.md` prose says "999
  files"; the `mirror-manifest.json` ground truth is **1,002 files / 2.06 GB**, each
  with a `done` status + sha256 (total 2,056,176,075 bytes). The app computes and
  shows **1,002** from the manifest — the verifiable number over the prose estimate.
  Flag for the founder: reconcile the S1 report prose to 1,002 at a later gate.

Workbench/Wells/Surfaces/Agents/Training/Audit ship as labelled "coming in P3+/P4/

## Notes / gotchas
- Launch config: `.claude/launch.json` `energy` entry uses `cwd: "apps/energy"` +
  `npm run dev` (NO `--prefix` — combining cwd and --prefix doubled the path and
  broke `preview_start`).
- JSON-import empty arrays infer as `never[]` under strict TS — `knowledge.json`
  notes cast through an explicit `Note` interface.
- computer-tool ref-clicks did not dispatch in this environment; verified tab
  switching / drill-in / ⌘K palette via injected DOM clicks instead — app logic OK.
