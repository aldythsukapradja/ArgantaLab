## Shared grammar (build once)
- **Cold open:** black + one line of type.
- **Splash:** the reactor ignites ([[The-Reactor]] intro state) — *identical across all four*.
- **Body:** three acts = the company's three offerings, one hero move per shot.
- **Statement cards:** Oasis-style bold type on ink.
- **Outro:** reactor settles to the mark ([[The-Reactor]] ending state) — *identical across all four*.
- **Audio:** one music system (stems that intensify), one VO voice = the ARGANTA voice (memory [[arganta-persona-canon]]).

## The real & factual rule
**Non-negotiable.** These films use only:
- Real product UIs (screen recordings of KinetikCircle, ArgantaLab, LashiraBloom, GeaVision, HQ).
- Real founder credibility (the 15-year subsurface journey, real publications count — never invented awards/employers).
- Real data visuals — **no fabricated metric shown as live**.
AI (Higgsfield) is used for the reactor, cinematic b-roll, transitions, atmospheres, and the influencer creators — never to fake a product capability or a statistic. This is what earns SLB-level trust.

## Production pipeline (asset ↔ edit)
```
REAL footage (product screens, founder)  ─┐
Higgsfield reactor splash/outro (Track E) ─┤
Higgsfield b-roll / cosmic / energy (H)   ─┼─→ EDIT (ArgantaStudio / Higgsfield edit)
Influencer creator clips (Track A)        ─┤     + VO (ARGANTA voice) + music stems
Statement type cards (design tokens)      ─┘     → 4 master films (16:9) → reframe 9:16/1:1
```
Cost discipline: a 3-min film is **mostly real footage + reused reactor + short AI b-roll shots**, not 3 minutes of generated video. Splash + outro are made once and shared. Full cost model & spend order: `docs/higgsfield/HIGGSFIELD-PUNCHLIST.md` (memory [[higgsfield-punchlist]]) — this film set = the new **Track I** to append there.
