# Arganta Perspectives

> One company truth. Four perspectives. Five chapters. Evidence behind every claim.

This note is the canonical editorial and build specification for the single-file Arganta Perspectives presentation. It preserves the complete detailed board in [[generated-media/arganta-icon-system-board.html]] while curating that knowledge for four audiences.

## Product decision

- Deliver one self-contained HTML file.
- Begin with a cinematic persona selector inspired by premium streaming profile selection, without copying Netflix assets or layout.
- Use the same five chapter names for all personas so a viewer can switch perspective without relearning the information architecture.
- Change emphasis, depth, expanded evidence and calls to action by persona.
- Navigate chapters horizontally with left/right controls, keyboard arrows and mobile swipe; each chapter may scroll internally only when its content exceeds the viewport.
- Use the canonical SVG symbols from the source board for every portfolio and agent identity.
- Retain the complete original evidence board inside Chapter 5 as an embedded archive so no icon, logo, competitor, source, assumption or operating point is lost.
- Port the finished file into ArgantaHQ as a first-class Company surface.
- This local/laptop version does not enforce confidentiality. Future hosted versions must generate persona-safe bundles or use authenticated access.

## Chapter 4 — How Arganta Operates

- Weekly company pulse: 45 minutes.
- Weekly Life pilot review: 30 minutes.

1. Explore — validated problem.
2. Incubate — working thin slice and repeated use.

- Decision and approval ledger.
