## Overlap and transferred ideas

### FACT — direct continuities

| Standalone Kinetik evidence | Later ArgantaLab evidence | Continuity |
|---|---|---|
| Family/friends circles and `circleId` naming in `5f77dd3` | canonical circle/family spine in `952676e` | Circle is the shared social unit |
| Today/Calendar/Ask/Apps/Me shell in `5f77dd3` | `apps/kinetik` Today, Calendar, Apps, Me and later agent surfaces | Household operating shell |
| Moments main tab in `7d17369`; real media in `cf21f97` | Supabase Moments in `e31f886` | Social memory/feed pillar |
| Manifest-driven single-file Store in `7dcaf5d` | Circle Game SDK/Builder in `7adeff5`; Forge/public runtime later | Creation and distribution of small apps/games |
| Google Sheets DataAPI adapter and future React/Firebase plan | React/Vite/Supabase repos and shared data layers | Adapter-first/cloud migration direction |
| PWA manifests/service worker | Vercel PWAs and Capacitor native wrappers | One web build across targets |

No Git ancestry proves code was copied directly from the standalone Kinetik repository into ArgantaLab. The continuities are supported by names, IA, concepts, and later implementation, not by a merge relationship.

### FACT — shared architecture by 2026-07-18

- Supabase identity/session patterns occur in the web, Kinetik, HQ, landing, and Lashira apps.
- `supabase/migration_spine.sql` and later migrations centralize identity, circles, family, wallet, games, analytics, and product-specific state.
- `@arganta/*` packages provide combat, character, audio, video, AI, agents, builder, brand, media, and usage capabilities to multiple apps.
- `circleBridge` and embed-session code connect product shells.
- Vercel configurations deploy separate frontends from the same repository; Capacitor wraps web and Kinetik.
- Brand OS registers the umbrella and individual product brands in one package.

### INFERENCE — how the vision converged

The evidence supports a convergence path rather than two independent apps: KinetikCircle becomes the household/social shell; ArgantaLab becomes the learning/creation engine; Circle HQ and Arganta Core become the operating/creator layer; the Arganta landing and Brand OS make them legible as one family. This is an architectural and product-direction inference. It is not evidence of market validation.
