The concept

Three pillars, one philosophy

The game is the motivation. Learning is the gate.

🌾 Harvest Moon

The loop: till, plant, water, harvest, sell, care. A home that evolves, seasons, festivals, a town of friends.

🐾 Pokémon

Your befriended Kins are Harvest Sprites — assignable helpers that auto-do chores. Cow, sheep, chicken are separate livestock.

🏰 NexusTK

A persistent shared world — real circle members visible in your valley — plus the layered Heroes sprite look.

The rule that runs everything

Two logins. Two XP sources. One engine.

👦 Kids — learn to grow

Kids earn XP only from the 6 World learning problems. Playing gives them no XP. The stronger they want their farmer or hero, the more they learn.

XP = learning💎 = learning

🧑 Adults — play to grow

Adults earn XP by playing (farming, combat) — because they likely won't do the rings. Same level formula, capped per source.

XP = playingcapped RPC

PixelLab factory

Data row → auto-prompt (locked palette + style-ref) → PNG → atlas → existing art seam → Pixi. Call the REST endpoint directly (SDK parser is broken); ground tiles need "fills edge to edge, no border".

Style bible

16px tiles, integer scaling only, high top-down 3/4, warm earth + sap-green + one seasonal accent, buildings bigger than characters, transition tiles not hard seams.

Build strategy

Phases — farm first, RPG additive

0

Reusable spine & scaffold

Twin of Kingdom. Reuse level/xp/stat SQL; add generic entity/levels_set/skill/quest + farm tables. Extract shared nipplejs + compositor. Kid-PIN / adult-Google login.

1

The Farm loop the gate

Plots (till/plant/water/harvest, server-side growth), evolving house, barn/coop livestock, Kins as Harvest Sprites, Bloom purse, level→power. Ship only when one day is genuinely fun.

2

Learning integration + attach

unlock_gate ↔ real 6-World rings (circle-combined), gate prompts, Bloom.tsx embed + sync-bloom.mjs, diamonds read-only HUD, tutorial + daily quests.

3

Bloom Command + Mining & City

Admin dashboard (twin of Command Center) + postMessage bridge. Maps 3–4 as MapDef rows. PixelLab batch for real art.

4

Town, social, seasons

Bloomridge + ~12 NPCs + friendship (no romance) + gifting, seasons + first festival, Supabase presence (real circle members), cosmetic outfits.

5

RPG expansion — dungeons/combat

Hollow Gate + 6 portals + enemies (reuse monster templates). Combat = nipplejs + skills rows. Hero class paths. All additive — no re-architecture. Kids: 0 combat XP (learn); adults: capped.
