# Campaign and Social Creative Review

## Summary

This is a creative review checkpoint, not an implementation workstream.

## Core Principle

> Review functioning work. Return recommendations. Do not take implementation ownership.

## When to Invoke

After one campaign produces a landing page, presentation, video, and social pack.

## Required Inputs

  - Campaign brief
  - Master narrative
  - All deliverables
  - Brand profile
  - Channel objectives

## Review Criteria

  - Message hierarchy
  - Narrative unity
  - Hook strength
  - Channel adaptation
  - Legibility
  - Safe zones
  - Pacing
  - Launch impact
  - Consistency

## Required Output

- What is already strong
- Top five issues ranked by impact
- Exact visual or narrative recommendations
- Mobile-specific concerns
- Brand-consistency concerns
- Performance-conscious alternatives
- One recommended final direction
- No code changes

## Handoff

Return recommendations to the original Opus or Sonnet owner.

The original owner decides, implements, tests, and documents the changes.
