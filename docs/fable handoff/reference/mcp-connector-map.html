THE CONNECTOR MAP
FOR SHIPPING ASSETS.

You're engineering-heavy and media-blind. Marketing needs assets at volume — video, voice, image, and the pipeline to publish them. MCP is the reach-out layer: it lets your agent call specialist generators and distribution surfaces as tools. This maps what to wire, in what order, and what's a connector vs. a decoy.

Already connected Verified · wire next Recommended Not a connector (client/decoy)
01MEDIA GENERATION image + video + character consistency
one connector, many models
Higgsfield
mcp.higgsfield.ai/mcp
verified
The single biggest unlock. One OAuth endpoint exposes 30+ image/video models — Veo 3.1, Kling 3.0, Sora 2, Seedance, Flux 2, Nano Banana Pro. Async job polling built for long agent loops. Runs on your Higgsfield plan credits, no API keys.
→ Soul character-training keeps the same face across hero/UGC/banner — this is what makes a consistent Kin/Arganta brand face across a whole campaign in one session.
HeyGen
avatar + talking-head video
recommended
Avatar video: script → voice → talking-head render in one agentic pass. Has an MCP surface. Different job from Higgsfield — this is presenter/explainer video, not cinematic B-roll.
→ Good for ArgantaLab explainer/demo videos where a friendly host walks a parent through the app.
Pixel art / SVG
native — no connector needed
you have this
Your Kin characters are already SVG, and Circle HQ has a Pixel Vault. Claude generates SVG/code-based art directly — no external generator required.
→ This is a skill, not an MCP: encode your palettes + sprite conventions once, reuse forever.
02VOICE & AUDIO narration, voice cloning,
sound for video
ElevenLabs
text-to-speech + voice clone
recommended
The standard for TTS and voice cloning, with an MCP server. Narration for reels, a consistent brand voice, multilingual (useful — you span Indonesian, English, Arabic markets).
→ Pairs with Higgsfield: generate the clip there, lay narration here, in one chain.
Higgsfield already syncs some audio on video models, so only add ElevenLabs when you need a specific cloned brand voice or standalone narration. Don't wire it just to have it — that's exactly the overkill the effort-scorer is meant to catch.
03WEB & RESEARCH clean web data, competitor +
lead intelligence
Firecrawl
npx firecrawl-mcp · OAuth
verified
Turns any URL into clean markdown/JSON — strips ads, nav, boilerplate. Search, scrape, crawl, extract. Cuts token cost ~80% vs feeding raw HTML.
→ Two direct uses: competitor teardown (how do rival kids-learning apps position?) and lead-gen (pull structured lists of schools/partners with contact data as an HTML doc).
Scholar Gateway
already connected
you have this
Academic search — already wired. Feeds your SPE/EAGE/WPC paper work, separate from the marketing stack but part of the same environment.

06NOT CONNECTORS — READ THIS things that look like connectors
but aren't
Hermes Agent
MCP client / harness
decoy
Hermes is a client, not a connector. It's a rival agent harness — same category as Claude Code, OpenClaw, NemoClaw. It consumes MCP servers; it isn't one.
→ You don't "add Hermes" to Claude. You'd only use it if you were running a different harness. Stay on Claude Code + Cowork; you don't need this.
OpenClaw / NemoClaw
MCP clients
decoy
Same story — alternative agent runtimes, not tools to wire in. They appear in Higgsfield's "compatible clients" list, which is what causes the confusion.
07THE MARKETING PIPELINE how the connectors chain into
one agentic run
STEP 01
Research
Firecrawl
Scrape competitors + pull leads. Feed positioning into the brief.
STEP 02
Concept + copy
Claude (native)
Campaign concept, hooks, captions. No connector — this is the model itself.
STEP 03
Generate assets
Higgsfield · +voice ElevenLabs
Video/image with a consistent brand face. Narration if needed.
STEP 04
Store + tag
Google Drive
Named, tagged, organized. Human review checkpoint here.
STEP 05
Publish + learn
Meta MCP (phase 2)
Ship to ad sets, read performance, iterate. Only after conversion is fixed.
The whole chain is one subagent-orchestrator run. That's the point of mapping it: each connector is an interchangeable block, and the orchestration — research → concept → generate → store → publish — is the same pattern as your code workflow, pointed at media instead of files. Reserve the pipeline design for Fable today; the connectors themselves you can wire on Opus any day.
