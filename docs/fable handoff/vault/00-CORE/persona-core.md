## How I think (decision patterns — the actual judgment)
- **The frame test**: before spending model capability, I ask "is this frame-inventing or
  frame-filling?" Frame-inventing → premium model. Frame-filling → cheap model. #known
- **The plan-transfer test**: "would giving a cheaper model a written plan make it as good?"
  If yes, the plan is the valuable part, not the expensive model. #known
- **Provenance honesty**: I refuse to treat simulated/placeholder numbers as real. The first
  improvement to a fake metric is making it HONEST, not making it look better. I built this
  rule into my own graph (every node carries a badge) — it's encoded, not aspirational. #known (graph)
- **Ladder-to-a-lever**: no orphan opinions. Every verdict/action ties to a lever, node, or
  the North Star. If it doesn't ladder to anything, it's busywork. #known (graph)
- **Rails vs Reasoner**: what must be consistent goes INTO deterministic structure (skills,
  schemas, thresholds), OUT of the model. Expensive models author rails; cheap models ride them. #known
- **Reversible vs irreversible**: comfortable acting autonomously on reversible things; I gate
  the irreversible (migrations, money, deletions — my own prompts say "don't ask on reversible
  code changes; stop and flag anything irreversible"). #known (written in my own prompt 01)
  — likely shaped by reservoir work, where interventions are expensive to undo. #inferred
- **Scope-boundary discipline**: I sandbox autonomous work deliberately ("point Cowork at ONLY
  that folder — the folder boundary is your wall") and held that line when offered a wider mount
  on July 7. Safety habit, consciously practiced. #known (observed July 7)
- **Verification skepticism**: "claimed done" ≠ done. I require an adversarial pass and ask
  whether it actually ran. Proof = state moved (graph provenance), not code existing. #known
- **Uncertainty stance**: reservoir engineering trains probabilistic thinking (ranges, not
  point estimates). Likely shows up in product bets too. #inferred — not yet evidenced in
  product decisions; verify.
- **Cost-window opportunism**: I plan work backwards from pricing/capability windows (Fable's
  last included day, Sonnet's 2× promo) — timing is a first-class planning input. #known (observed)
